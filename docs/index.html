Install

One line. Then say “vibe check my app”.

Pick your tool. The installer copies the skill, prints what it did, and touches nothing else.

Option A: install it as a plugin inside Claude Code

› /plugin marketplace add vynemastudio/vibe-check

$ curl -fsSL https://vynemastudio.github.io/vibe-check/install.sh | bash -s -- --claude

Then, in your app's folder, ask Claude: “vibe check my app”.

Run this in your project folder. It adds a Cursor rule and the skill files.

$ curl -fsSL https://vynemastudio.github.io/vibe-check/install.sh | bash -s -- --codex

FAQ

Questions

Does a clean report mean my app is legally compliant?

No. Vibe Check finds common gaps in code and explains them. Whether a law applies depends on your users, location, revenue and facts, which code can't show. Treat it as a pre-launch checklist, not legal sign-off.

Does my code leave my machine?

The scanner runs locally with zero dependencies and makes no network calls. The AI part runs in whatever agent you already use (Claude Code, Cursor or Codex), under that tool's own data terms.

Which stacks does it understand?

Anything web: plain HTML, React, Next.js, Vue, Svelte, Astro, Supabase, Firebase, Stripe and more. The scanner reads source files; the agent handles everything it can't decide statically.

Is it really free?

Yes. It's MIT-licensed and open source on GitHub. Fixes and new checks are welcome.

Is the €100 Google Fonts fine real?

A Munich court in 2022 awarded €100 to one visitor whose IP was sent to Google without consent. It isn't €100 per visitor, and a 2023 ruling rejected mass "crawler" claims. The risk is real but modest, and the fix takes two minutes.

How do I uninstall?

Delete ~/.claude/skills/vibe-check (or run /plugin uninstall vibe-check), .cursor/vibe-check with .cursor/rules/vibe-check.mdc, or .agents/vibe-check along with the marked section in AGENTS.md.

Educational, not legal advice. Vibe Check is an educational tool. It doesn't create a lawyer–client relationship, and a passing report doesn't mean your app complies with any law. Penalty figures are statutory maximums or single rulings, shown for context. Laws change and depend on your facts, so consult a qualified lawyer. See sources.
