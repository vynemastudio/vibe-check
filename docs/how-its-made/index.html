How it's made

A 30-second 3D explainer, built entirely in code.

No stock footage, no video editor, only free and open-source tools. Everything is deterministic: the same code renders the same frames every time. Here's the whole pipeline, the steps, the prompts and a tiny example you can run.

The pipelineSeven stages, script to master

  1. Script → voice.

    One clause per line, voiced with Kokoro TTS (open-weights, voice af_heart, about 195 words per minute). Silences are trimmed to about 100 ms by deleting silent samples, so pitch never changes. Deliberate pauses go before big moments.

  2. Word timing.

    faster-whisper transcribes each line with word timestamps, matched back to the script spelling. That drives the kinetic captions with the current word highlighted.

  3. 3D scenes in three.js.

    An original low-poly car, a curved loop ramp, airflow particles, a pressure-field shader, force arrows, thruster plumes and keyframed cameras. Every object's state is a pure function of time t, so any frame can be rendered on its own.

  4. Frame-by-frame render.

    Playwright drives headless Chromium, calls window.frame(t) for each frame and pipes the image into ffmpeg (H.264). Fast shots average three sub-frames for motion blur. The render is split across 8 parallel workers.

  5. Sound design in numpy.

    Whooshes from band-passed noise, fan whine from stacked harmonics, gas hiss, pitch-dropping impacts and a 124 bpm pulse bed that ducks under the voice, all placed on the same beat times as the visuals.

  6. Master.

    Two-pass ffmpeg loudnorm to −14 LUFS integrated, then an oversampled limiter for a true peak under −1 dBTP, the usual target for Reels and Shorts.

  7. QA.

    ffmpeg blackdetect and freezedetect, an ebur128 loudness check and a 16-frame contact sheet.

Do it yourselfSteps to make your own

  1. Pick a topic and verify every fact against 2–3 sources. Write the numbers into a sources file before you write the script.
  2. Write a 60–80 word script with one idea every 2–3 seconds and a hook in the first line.
  3. Storyboard the beats as a table: time, picture, on-screen text, voice-over.
  4. Build reusable components first (vehicle, environment, effects, camera), then compose scenes around the beat times.
  5. Render a low-res preview of the hook and the hardest shot, watch it with the sound off, and fix it.
  6. Render the full film, add sound, master, run QA and export a smaller share copy.

PromptsExample prompts for Claude Code, Cursor or Codex

  • Write a three.js function Vehicle3D() that builds an original low-poly wedge sports car from an extruded side profile, with flat-shaded metallic paint, 4 wheels, and an update({t, xray}) method that turns the shell translucent and shows lime blueprint edges.
  • Make a CurvedRamp({R, run, ceil}): a flat run-in, a half loop of radius R and an inverted ceiling section. Return at(s) giving position, tangent and up vector at arc length s, so objects can be posed on it.
  • Create a deterministic particle airflow: particles flow from a car's side skirts toward 4 fan positions under the rear, then out the back. Position must be a pure function of time.
  • Write a Playwright script that loads scene.html, calls window.frame(t) for every frame at 30 fps, and pipes JPEGs into ffmpeg as H.264. Support splitting the frame range across N parallel workers.
  • In numpy, synthesise a whoosh, a fan whine, a gas hiss and a bass impact, place them at given timestamps, add a pulse bed that ducks under a voice track, and write a 48 kHz WAV.
  • Normalise this mix to −14 LUFS with true peak below −1 dBTP using two-pass ffmpeg loudnorm.

Minimal exampleA deterministic three.js frame renderer

Two files. scene.html exposes window.frame(t); render.mjs steps t frame by frame and pipes the images to ffmpeg. Because time comes from the frame number and not the clock, a slow machine produces exactly the same video as a fast one.

npm i playwright && npx playwright install chromium   # plus ffmpeg on your PATH
node render.mjs 4 30        # 4 seconds at 30 fps -> out.mp4 (1080x1920)

import * as THREE from 'three';
const W = 1080, H = 1920;
const renderer = new THREE.WebGLRenderer({ antialias: true, preserveDrawingBuffer: true });
renderer.setSize(W, H); renderer.setPixelRatio(1); document.body.appendChild(renderer.domElement);
const scene = new THREE.Scene(); scene.background = new THREE.Color('#0B0E13');
const camera = new THREE.PerspectiveCamera(35, W / H, 0.1, 100);
scene.add(new THREE.HemisphereLight('#F5F5F2', '#0B0E13', 1.2));
const key = new THREE.DirectionalLight('#ffffff', 2); key.position.set(3, 5, 4); scene.add(key);
const cube = new THREE.Mesh(new THREE.IcosahedronGeometry(1, 1),
  new THREE.MeshStandardMaterial({ color: '#C5FF4A', flatShading: true, metalness: 0.3, roughness: 0.4 }));
scene.add(cube);
const ease = x => x < 0.5 ? 4 * x * x * x : 1 - Math.pow(-2 * x + 2, 3) / 2;

// The whole trick: every frame is a pure function of t (seconds). No clocks, no Math.random.
window.frame = (t) => {
  cube.rotation.set(t * 0.6, t * 0.9, 0);
  cube.scale.setScalar(0.6 + 0.4 * ease(Math.min(t / 1.5, 1)));
  const a = t * 0.4;
  camera.position.set(Math.sin(a) * 6, 1.5, Math.cos(a) * 6); camera.lookAt(0, 0, 0);
  renderer.render(scene, camera);
};
window.ready = true;
</script></body></html>
render.mjs
// Render scene.html frame by frame to out.mp4. MIT License (c) 2026 Vynema Studio.
// npm i playwright && npx playwright install chromium ; needs ffmpeg on PATH
// node render.mjs [seconds=4] [fps=30]
import { chromium } from 'playwright';
import { spawn } from 'child_process';
import path from 'path';
const secs = +(process.argv[2] || 4), fps = +(process.argv[3] || 30);
const ff = spawn('ffmpeg', ['-y', '-loglevel', 'error', '-f', 'image2pipe', '-framerate', String(fps), '-i', '-',
  '-c:v', 'libx264', '-pix_fmt', 'yuv420p', '-crf', '18', '-movflags', '+faststart', 'out.mp4'], { stdio: ['pipe', 'inherit', 'inherit'] });
const browser = await chromium.launch({ args: ['--use-angle=swiftshader', '--enable-unsafe-swiftshader'] });
const page = await browser.newPage({ viewport: { width: 1080, height: 1920 } });
await page.goto('file://' + path.resolve('scene.html'));
await page.waitForFunction(() => window.ready);
for (let i = 0; i < secs * fps; i++) {
  await page.evaluate(t => window.frame(t), i / fps);          // frame time, not wall-clock time
  const png = await page.screenshot({ type: 'jpeg', quality: 92 });
  if (!ff.stdin.write(png)) await new Promise(r => ff.stdin.once('drain', r));
}
ff.stdin.end(); await browser.close();
await new Promise(r => ff.on('close', r)); console.log('wrote out.mp4');
